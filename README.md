# 공용차 교통사고 대응 매뉴얼

한국산업인력공단 강원동부지사 차량 비치용 모바일 웹페이지입니다.
확정 연락처: **강원동부지사 안전담당 · 033-650-5744 / 033-650-5745**.
두 번호는 내부 연락처, STEP 05, 현장 대응 모드 STEP 05, QR 안내카드에 각각 전화 링크로 표시합니다. 개인 이름은 표시하지 않습니다.

## 바로 열기

이 폴더의 `index.html`을 브라우저로 열면 기본 절차와 전화 버튼이 작동합니다.
`print.html`은 차량 비치용 A6 카드입니다. 인쇄 배치에서 A4 4장도 선택할 수 있습니다.
위치 조회와 클립보드는 HTTPS 또는 localhost에서 브라우저 권한에 따라 작동합니다.
조회·복사에 실패하면 직접 입력하거나 선택하여 복사할 수 있습니다.

Node.js가 있다면 추가 설치 없이 이 폴더에서 실행합니다.

```text
npm start
```

로컬 주소: http://127.0.0.1:4173
검증: `npm test` / 배포 파일 준비: `npm run build` (`_site/` 생성)

## GitHub Pages 배포

이 폴더 전체를 **독립 GitHub 저장소의 최상위**에 올리세요.
기존 상위 대시보드의 파일이나 .env는 이 저장소에 포함하지 않습니다.

1. 저장소의 기본 브랜치를 `main`으로 설정합니다.
2. Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다.
3. 포함된 `.github/workflows/pages.yml`이 검사 후 정적 파일만 `_site/`로 패키징하여 배포합니다. 설치나 서버는 필요 없습니다.
4. 실제 생성된 HTTPS 주소를 확인하고 `config.js`의 `deploymentUrl`에 매뉴얼 `index.html`의 주소 또는 매뉴얼 폴더의 끝이 /인 주소를 입력합니다.
5. 다시 배포한 다음 `print.html`에서 QR이 그 주소로 생성되는지 확인합니다. 주소를 임의로 가정하지 않습니다.
6. 실제 휴대전화로 접속·새로고침·전화 연결·QR 인식과 인쇄 크기를 확인한 뒤 비치합니다.

자동 배포가 필요 없다면 `_site/`의 내용만 별도 저장소 최상위로 올린 뒤 Pages의 Deploy from a branch를 사용해도 됩니다.
저장소를 이 프로젝트 폴더를 포함하는 형태로 올릴 경우 Actions의 작업 경로와 업로드 경로를 해당 폴더에 맞게 바꿔야 합니다.
정적 파일은 모두 상대 경로이므로 GitHub Pages의 저장소 하위 경로에서도 작동합니다.
배포 주소는 현재 미확정이므로 QR은 **배포 주소 설정 후 생성** 상태입니다.
이번 작업은 코드 및 배포 구성 준비이며 원격 GitHub 게시를 수행하지 않았습니다.

## 수정 위치

### 확정 연락처

`config.js`의 `internalContact`에서 담당 표기와 전화번호를 관리합니다.
전화 링크는 숫자만 남겨 생성하며, 네 영역에 같은 설정을 적용합니다.
스크립트가 꺼져도 전화할 수 있도록 `index.html`의 내부 연락처와 STEP 05, `print.html`의 정적 전화 링크도 함께 수정하세요.
`scripts/check.mjs`의 연락처 검증도 갱신하세요.

### 로고 원본

첨부 파일을 재작성·리사이즈·색상 변환 없이 그대로 프로젝트에 복사했습니다.

| 원본 파일 | 프로젝트 파일 | 적용 위치 |
| --- | --- | --- |
| 시그니처 지사_좌우조합B 강원동부.png | assets/logo-horizontal-b.png | 모바일 기본 상단 |
| 시그니처 지사_상하조합 강원동부.png | assets/logo-vertical.png | A6 세로 카드 |
| 시그니처 지사_좌우조합A 강원동부.png | assets/logo-horizontal-a.png | 900px 이상 PC 상단 |

흰색 배경, 여백, `object-fit: contain`, `height: auto`를 적용했습니다.
모든 로고 대체 텍스트는 “한국산업인력공단 강원동부지사”입니다.
QR 내부에는 로고를 삽입하지 않습니다.
`assets/originals.json`은 복사한 원본 파일의 SHA-256 기록입니다.

### 차량별 정보

`config.js`의 `vehicles` 배열에 실제 차량의 다음 정보를 입력합니다.

```js
{
  id: "car-01",           // 공개해도 되는 식별자
  plate: "확정 차량번호",
  model: "확정 차종",
  insurer: "실제 가입 보험사",
  accidentPhone: "확인된 사고접수 전화번호"
}
```

실제 정보가 없으므로 기본 배열은 비어 있습니다. 예시 차량을 운영 차량으로 등록하지 않았습니다.
전화번호가 미확정이면 빈 문자열로 두세요. 해당 전화 버튼은 비활성화됩니다.
차량 QR 주소는 `index.html?vehicle=car-01`입니다.
알 수 없거나 중복된 식별자는 다른 차량으로 대체하지 않습니다.
QR 안내카드에서 차량 선택 시 해당 차량과 보험 연락처가 함께 표시됩니다.
개인 휴대전화, 보험증권 번호, 인증정보는 공개 설정이나 QR에 넣지 마세요.

### 배포 주소·버전

`config.js`의 `deploymentUrl`, `version`, `reviewedAt`을 변경하세요.
안내 본문은 `index.html`, 카드 내용은 `print.html`, 인쇄 크기는 `print.css`입니다.
한 번 접속한 데이터를 저장하는 서비스워커는 사용하지 않습니다.
최초 접속에는 통신이 필요하고, 별도 오프라인 저장은 보장하지 않습니다.
인쇄물 자체에 기본 행동과 119·112·내부 연락처를 표시했습니다.

## 기능과 개인정보

- 기본 화면에서 전체 6단계를 읽고, 현장 모드에서 한 단계씩 볼 수 있습니다. 체크 여부와 관계없이 다음 단계로 이동합니다.
- 사고 직후 STEP 01~05와 사고 이후 STEP 06을 구분합니다. 긴급 구조·신고는 순서와 관계없이 즉시 또는 병행합니다.
- 위치는 버튼 클릭 시에만 조회합니다. 좌표를 실제 도로명이나 진행 방향으로 추정하지 않습니다.
- 지도 열기를 누를 때만 외부 지도에 좌표를 전달합니다. 위치 자동 신고는 하지 않습니다.
- 보고 문구의 빈 항목은 미확인으로 처리합니다. 서버 전송·로컬 저장·사진 업로드·분석 도구는 없습니다.
- 클립보드 권한이 없으면 내용 선택과 직접 복사를 안내합니다. 초기화 버튼이 있습니다.
- 외부 글꼴·이미지 서버·인증 서버·DB·CDN을 사용하지 않습니다. QR 라이브러리도 프로젝트 안에 포함했습니다.
- 인쇄 QR은 실제 배포 주소를 설정한 뒤 생성합니다. 4모듈 이상의 흰 여백을 확보하고 35mm 크기로 출력합니다.
- 너무 긴 주소로 작은 인쇄 QR의 밀도가 높아지면 생성을 중단합니다. 이때 안정적인 짧은 주소를 설정하세요.
